# Visual review

This note covers the original starter assets. See `pack2/QUALITY_NOTES.md`
for the twenty additional normals and twenty sci-fi and line alphas.

The final 1024 set was reviewed in both contact sheets and in full-resolution
2x2 Brick, Cobblestone, HexTiles, and WoodPlanks previews. No visible border
discontinuities or smooth-alpha contour bands were found. These are useful
starter assets; the following artistic details could be improved:

- DiamondPlate has fairly small, narrow raised diamonds. Broader lozenges and
  slightly variable wear would make a more heavy-duty industrial plate.
- ReptileScales is deliberately regular. A next version could introduce
  stronger size variation and asymmetry while preserving the overlapping rows.
- WoodPlanks has readable knots but clean, regular grain. A second timber
  variant could add more uneven growth rings, split ends, and weathering.
- HammeredMetal has many overlapping dents, giving a busy surface. Fewer,
  more isolated bowls would suit a lightly hammered material.
- DryBrush is quite broken; it suits a scratchy dry tip. A denser variant
  would give more continuous paint coverage.
- OilStroke bristle tracks are more regular than a hand-painted stroke.
  More varying bristle spacing and occasional interruptions would add character.

No material previews in the running SubCraft app were used for this review;
actual appearance also depends on lighting, UV scale, and normal strength.
