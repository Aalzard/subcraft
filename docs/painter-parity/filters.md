## Generic filter UI

Layout notes: A filter is an effect row in a layer's content stack or its mask stack. Adding it creates an empty Filter effect; Properties then shows a Filter selection button that opens the mini shelf, followed by the picked filter's parameters, per-channel toggles (content) and the effect's blending mode and opacity. Dragging a filter from the Assets panel into the layer stack instead creates a layer whose channels are all set to Passthrough, so the filter processes everything below it. The Assets panel groups the default filters as Standard, Finishes, MatFX, Lighting and Advanced (the grouping used below). The filter pages give no numeric defaults or ranges except where noted. SubCraft has 26 built-in filters (crates/doc/src/filter.rs:112) picked from a combo box or the Shelf's Filters tab; a content filter works on one chosen channel.
