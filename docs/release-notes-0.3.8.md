SubCraft 0.3.8.

- **Invert zoom**: a setting for the mouse wheel direction in the 3D and 2D views, plus Painter's camera, zoom and wheel speed settings.
- **Path tools** like Painter's: filled paths, the brush tip along a path, ribbon paths and a Paths panel. **Warp projection** with an editable grid.
- **Layer instancing**: instance layers and Paste as instance, also across texture sets.
- **22 more channel types** (coat, sheen, anisotropy, scattering and more).
- **Symmetry** display, manipulator and mirror planes; L switches it on and off.
- **Viewport**: order-independent transparency, temporal anti-aliasing, shadows, display-mode dropdowns, Normal + Height display.
- **2D view**: zoom on the cursor and rotate the texture with Alt+LMB.
- **Export**: a template editor like Painter's, about 25 more built-in templates, converted maps, Export flattened / mask from the layer stack, File > Export mesh, Netpbm formats, export window tabs.
- **Faster**: single-channel edits 2-3.6x faster at 4K, faster edits in deep stacks, and projects open up to 3x faster.
- About 60 fixes.

Full details: [CHANGELOG.md](https://github.com/Aalzard/subcraft/blob/main/CHANGELOG.md).

**Windows build is not code-signed.** SmartScreen may warn on first run: choose More info, then Run anyway. Check the download against `SHA256SUMS.txt`.

**Files:** Windows installer (`SubCraft-0.3.8-setup.exe`), portable zip, Linux x86_64 tarball (built by CI, not run by hand), and checksums.
