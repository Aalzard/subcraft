SubCraft 0.4.1.

- **SubCraft Materials pack**: download it in one click from the Assets panel, then drag its materials onto the model or into the layer stack.
- **Polygon Fill**: Polygon loop and Partial polygon loop modes, a wireframe of the active texture set while the tool is active, box Hit-test, Shift+A for a temporary loop, and a Blending mode.
- **Shelf Generators**: every generator in the Shelf; drag one into a mask or onto the model.
- **New filters**: Anisotropic Kuwahara and Quantize.
- **Levels**: drag the input, midtone and output handles on the histogram.
- Baking: more Thickness and Position baker settings.
- Also: images dropped from the OS become layers, Shelf items drop between effect rows, "Only display the selected material when painting", a Mask entry in the View dropdown, and Ctrl+6 for the Clone tool with an absolute source.

Full details: [CHANGELOG.md](https://github.com/Aalzard/subcraft/blob/main/CHANGELOG.md).

**Windows build is not code-signed.** SmartScreen may warn on first run: choose More info, then Run anyway. Check the download against `SHA256SUMS.txt`.

**Files:** Windows installer (`SubCraft-0.4.1-setup.exe`), portable zip, Linux x86_64 tarball (built by CI, not run by hand), and checksums.
