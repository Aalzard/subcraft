# Alignment test pair

Two small models for trying the Bake window's **Placement** tools.

* `crate_low.obj` — the low poly: a plain 1.6 x 1 x 1 box with UVs.
* `crate_high_misaligned.obj` — a detailed crate (rounded corners, plank grooves, rivets) that is
  **deliberately scaled 1.35x and moved** (the way an image-to-3D result often arrives).

Open `crate_low.obj` in SubCraft, open **Bake**, choose `crate_high_misaligned.obj` as the high poly
and press **Auto align**. The blue high poly then sits exactly on the red low poly.

They are generated by a script, so they can be recreated at any time:

```bash
cargo run -p subcraft-mesh --example make_alignment_demo
```
